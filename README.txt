RAILWAY RESERVATION AND TATKAL TICKET BOOKING SIMULATION ENGINE

Technology: Java, Java Swing, OOP, ArrayList

Run in VS Code:
1. Install JDK 8 or above.
2. Open this folder in VS Code.
3. In the terminal, run: javac *.java
4. Then run: java Main

Features:
- GUI login (enter any non-empty username)
- Train selection
- Normal and Tatkal booking simulation
- Seat availability and allocation
- PNR generation and ticket confirmation
- Booking history
- Ticket cancellation by PNR
- Seat restoration after cancellation

Important: Educational simulation only; not connected to IRCTC or real railway booking.
Booking information is stored in memory and is cleared when the application closes.
